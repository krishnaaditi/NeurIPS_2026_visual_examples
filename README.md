# NeurIPS_2026_visual_examples

We have added representative failure-case visualizations in this repository. The examples show that the remaining failures mainly occur when the target object is very small and partially occluded (spoon), extremely small and barely visible in a crowded scene (bird), partially occluded and visually blends with a similar background (snowboard), or small and far from the camera (baseball glove). These challenging cases provide insufficient visual evidence for reliable recognition, causing both the baseline and PURGE-trained models to fail.
